# 县域医共体信息化平台 开发时间计划

> 依据《县域医共体信息化平台建设规划》第八章"实施路径与分期计划"细化。
> 计划起点：2026年8月。采用双周迭代（Sprint），每月末为里程碑检查点。
> 团队假设：平台组（后端4人、前端3人）、业务组（共享中心3人、公卫2人）、数据组2人、测试2人、实施运维2人。

## 一、总体里程碑

| 里程碑 | 时间 | 交付物 | 验收标准 |
|---|---|---|---|
| M0 平台立项与骨架 | 2026-08 | 基础平台工程骨架（本次已交付） | 统一认证、机构、EMPI、编码字典、双向转诊接口可用，测试通过 |
| M1 数据底座 | 2026-10 | 医共体大数据中心 v1 | "四统一"字典全量导入，数据交换接口对接1家试点乡镇卫生院 |
| M2 核心共享中心 | 2027-01 | 影像/心电/检验三中心 | "基层检查、上级诊断"闭环走通，危急值管理上线 |
| M3 审方与药事 | 2027-03 | 集中审方中心+中心药房 | 前置审方接入全部成员单位处方，中心药房库存/调拨上线 |
| M4 互认与惠民 | 2027-05 | 结果互认+先诊疗后结算+档案开放 | 常规检验检查项目互认，居民端可查询本人健康档案 |
| M5 一期验收 | 2027-07 | 一期整体验收 | 等保测评通过、灾备演练完成、121号文年度指标达标 |
| M6 扩面协同 | 2027-08 ~ 2028-07 | 二期全部应用 | 36项功能全部上线，远程医疗到村，驾驶舱运行 |
| M7 智能提升 | 2028-08 起 | AI与监测预警深化 | AI辅诊/智能审方/多点触发预警投用，监测指标持续向好 |

## 二、第一期逐月计划（2026-08 ~ 2027-07）

### 2026-08（Sprint 1-2）：平台骨架 ✅ 已开始
- [x] 工程脚手架：FastAPI 后端、SQLAlchemy 数据层、pytest 测试框架
- [x] 统一认证：登录、JWT 令牌、角色权限（admin/doctor/operator）
- [x] 机构管理：县-乡-村三级机构树（牵头医院/乡镇卫生院/村卫生室/公卫机构）
- [x] 患者主索引 EMPI：身份证去重、电子健康卡号生成、幂等建档
- [x] 统一编码字典：诊断/药品/耗材/收费"四统一"字典框架
- [x] 双向转诊：上转/下转申请与状态流转（待接诊→接诊→结案/退回）
- [ ] 管理端前端壳工程（Vue3 + Vite）：登录页、机构管理页

### 2026-09（Sprint 3-4）：认证与门户完善
- 用户管理界面、机构人员账号开通流程
- 电子健康卡对接省平台注册服务（实名认证、一码通生成）
- 数据库切换 PostgreSQL，接入统一云管环境
- CI 流水线（自动测试+构建）

### 2026-10（Sprint 5-6）：数据底座（里程碑 M1）
- 大数据中心库表模型：电子病历库、健康档案库、检查检验库
- ICD-10、国家药品编码等标准字典全量导入工具
- 数据交换服务：HL7/自定义接口接入试点机构 HIS
- 数据质控规则引擎 v1（完整性、值域校验）

### 2026-11 ~ 2026-12（Sprint 7-10）：影像与心电中心
- 影像中心：申请管理、DICOM 传输/浏览、诊断报告发布/回传、排班、报告模板
- 心电中心：心电采集接入、诊断任务分配、危急值管理、移动诊断
- 患者360视图 v1（就诊记录+检查检验汇总）

### 2027-01（Sprint 11-12）：检验中心（里程碑 M2）
- 检验中心：电子开单→条码→采样→物流转运→核收→检测→审核发布全流程
- 三中心联调，与试点乡镇卫生院完成"基层检查、上级诊断"业务验证

### 2027-02 ~ 2027-03（Sprint 13-16）：审方与药事（里程碑 M3）
- 集中审方："系统+药师"双审、用药规则库、处方流转、处方点评
- 中心药房：药品耗材采购/库存/调拨/配送、县乡村余缺调度
- 转诊会诊中心：会诊申请/审核、病历调阅、会诊记录与评估

### 2027-04 ~ 2027-05（Sprint 17-20）：互认与惠民（里程碑 M4）
- 检验检查结果互认：互认项目/规则管理、互认推送、不互认理由、监管统计
- "先诊疗、后结算"：与医保结算系统对接
- 居民端（小程序/公众号）：预约挂号、报告查询、电子健康档案本人开放
- 慢病膳食运动指导要点嵌入接诊/随访界面

### 2027-06 ~ 2027-07（Sprint 21-24）：安全加固与一期验收（里程碑 M5）
- 等保三级测评整改、商用密码应用改造、灾备部署与切换演练
- 性能压测与容量规划、运维监控告警体系
- 全员培训、试运行、一期验收

## 三、第二期季度计划（2027-08 ~ 2028-07）

| 季度 | 内容 |
|---|---|
| 2027 Q3 | 病理、消毒供应、智慧急救中心；远程会诊上联省市三甲 |
| 2027 Q4 | 互联网+诊疗/慢病/家医签约；共享中药房、中医智能辅诊；远程医疗延伸到村卫生室 |
| 2028 Q1 | 医防融合：慢病/老年/妇幼/疫苗协同，传染病监测前置软件部署；医保"村村通" |
| 2028 Q2 | 人财物/绩效/医废统一管理系统；综合决策驾驶舱（内置监测指标体系14项指标） |

## 四、第三期（2028-08 起，滚动规划）

- AI 辅助诊断（影像/心电初筛）、智能审方升级、智能导诊
- 多点触发传染病监测预警、智能流调
- 居民用药监测画像、健康随访与积分激励（"健康云银行"模式）
- 按监测指标体系逐季评估，滚动优化

## 五、风险与应对

| 风险 | 应对 |
|---|---|
| 各机构 HIS 厂商接口配合慢 | 先以试点机构打样，接口规范文档化，纳入采购合同约束 |
| 编码"四统一"历史数据映射工作量大 | 数据组专项，先增量后存量，映射工具+人工复核 |
| 等保/密评周期长 | 2027-02 提前启动测评机构对接，边建边测 |
| 基层网络与终端条件差 | 实施组前置摸底，弱网优化（断点续传、离线缓存） |
