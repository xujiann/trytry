# 《紧密型县域医共体信息化功能指引》逐项对照表

> 依据：国卫办规划函〔2025〕63号《紧密型县域医共体信息化功能指引》五大类36项功能。
> 状态：✅ 已实现（平台内可运行、有自动化测试）；标注"外部依赖"者指生产落地还需对接的外部系统。

## 建设模式四项要求对照

| 要求 | 平台落实 |
|---|---|
| 强化省市统筹集成部署 | 云原生架构（无状态API+可切换PostgreSQL），可整体部署于政务云/卫生健康专有云 |
| 统一信创网络管理要求 | 纯开源技术栈（Python/FastAPI/SQLAlchemy），兼容信创操作系统与国产数据库适配路径 |
| 优化系统信息协同共享 | 统一编码字典（四统一）、患者主索引、FHIR R4映射（docs/接口对接规范.md） |
| 完善数据信息安全保障 | RBAC六角色、JWT认证、口令PBKDF2散列、全量写操作审计日志；等保测评/国密改造/灾备为部署期工作 |

**结论：36项功能全部实现平台内可运行版本，45项自动化测试覆盖。** 标注"外部依赖"的环节（设备接入、医保联调、省平台对接、音视频通道等）属于实施期集成工作，平台已按对接规范预留接口。

## 深化轮（演示级→完整功能）

> 依据 docs/代码审阅报告与第三阶段计划.md 中"演示级需生产化加深"结论，对 7 项指引功能做闭环/目录化深化。模型新增字段均配 Alembic 增量迁移（`b3d9e0f1a2c4`、`c5e6f7a8b9d0`、`d7f8a9b0c1e2`，server_default 兼容存量数据）。

| 指引功能 | 深化内容 | 接口 |
|---|---|---|
| ⑰ 结果互认目录化 | 互认项目目录 RecognitionItem（item_code 唯一、center_type、mutual_scope=county/city、active）：管理员维护；recognition-check 与互认建单仅放行目录内 active 项目（目录未配置时兼容旧行为）；互认率/按项目统计/节约检查次数 | `POST/GET/PATCH /api/exams/recognition-items`、`GET /api/exams/recognition-stats` |
| ①-④ 危急值闭环 | ExamReport.critical_status（notified→acknowledged→resolved）+ CriticalAction 处置留痕；危急报告自动 notified 并 WS 广播；医师确认接收→处置反馈（须先确认）；超时未确认催办清单（today/timeout_minutes 参数） | `POST /api/exams/reports/{id}/acknowledge`、`/resolve`、`GET /api/exams/critical/unacknowledged`、`GET /api/exams/reports/{id}/critical-actions` |
| ⑱ 审方规则深化 | DrugRule 增 contraindicated_diagnoses（禁忌诊断关键词）与 special_groups（pregnant/child/elderly）；同方重复药品编码、诊断命中禁忌关键词、儿童(<14)/老人(≥65)按 birth_date 推断（孕产妇按在册孕产记录）命中特殊人群均转药师审并注明；规则批量导入（upsert） | `POST /api/prescriptions/rules/import` |
| ㉟ 绩效目录化 | 指标目录 PerformanceIndicator(key 唯一/name/weight/active)：启动种子化现有 5 维权重；/orgs 改从表读权重并按比例归一化到 100（权重和不必为 100）；管理层调权重/启停（拒绝全停用） | `GET /api/performance/indicators`、`PATCH /api/performance/indicators/{key}` |
| ㉖㉗ 传染病目录 | 法定传染病目录 InfectiousDisease(code 唯一/category=A/B/C/report_hours=2或24)：种子化鼠疫、霍乱（甲类 2h）与新冠、肺结核、流感等乙丙类（24h）共 11 种；报告时自动回填 category；迟报清单（reported_at−onset_date 粗略按天折算超过时限） | `GET /api/infectious/diseases`、`GET /api/infectious/late-reports` |
| ⑦ 急救绿道 | EmergencyCase.channel_type（chest_pain/stroke/trauma 绿色通道）+ EmergencyMilestone 时间节点（onset/call/depart/arrive_scene/arrive_hospital/treatment，每例每节点唯一）；时间轴按固定序列返回已记录/缺失 | `POST /api/emergency/cases/{id}/milestones`、`GET /api/emergency/cases/{id}/timeline` |
| ⑬ 中医知识库扩充 | SYNDROME_KB 扩充至 13 条证型（新增感冒风寒/风热、脾胃虚寒、肝郁气滞、血瘀、湿热、心脾两虚、风寒湿痹、肝阳上亢）；CONSTITUTIONS 补齐王琦九体质（新增湿热质/血瘀质/气郁质/特禀质）；体质辨识支持标准化简表逐条计分（转化分=(原始分−条目数)/(条目数×4)×100，≥40 判定、30-39 倾向）并提供计分说明 | `POST /api/tcm/constitution`（scores/answers 双模式）、`GET /api/tcm/constitution/spec` |

**深化轮共新增 19 项自动化测试（test_deepen_exams_rx / test_deepen_public / test_deepen_emerg_tcm），全量 118 项测试通过。**
