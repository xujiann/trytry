# 县域医共体信息化平台 用户手册（V1.0）

> 适用对象：平台六类角色的业务用户与居民。管理端入口 `http://<平台地址>/`，
> 居民端 H5 入口 `http://<平台地址>/m`。
> 角色由管理员在"用户管理"中分配：平台管理员（admin）、管理层（director）、
> 医师（doctor）、药师（pharmacist）、公卫人员（public_health）、经办人员（operator）。

## 第零章 通用操作（所有角色）

1. **登录**：打开管理端首页，输入用户名/密码。连续输错 5 次锁定 10 分钟。
2. **导航**：左侧菜单按"总览/基础平台/业务协同/医防融合/便民惠民/综合管理/系统管理"
   分组；无权限的页面不显示（页面可见≠可操作，写操作按角色矩阵校验，无权时提示 403）。
3. **修改密码**：任何角色都应定期修改（≥8 位且含字母数字）。修改后所有已登录
   会话立即失效，需重新登录。
4. **退出登录**：退出后当前令牌立即作废。
5. **实时提醒**：登录后自动建立推送通道，危急值（发往申请机构）与缺药预警会弹出提醒。

## 第一章 平台管理员（admin）

管理员可见并可操作全部页面。专属页面与关键配置职责如下。

### 页面清单（专属/主责）

| 页面 | 主要职责 |
|---|---|
| 用户管理 | 建账号、分配六类角色与所属机构 |
| 审计日志 | 全部写操作留痕查询、按月导出归档 |
| 机构管理 | 维护医共体成员单位（牵头医院/卫生院/村室/公卫机构）与层级 |
| 编码字典 | 诊断/药品/耗材/收费"四统一"编码维护 |
| 共享诊断中心-互认目录 | 互认项目增删改（中心类型、县域/市级范围、启停） |
| 集中审方-规则库 | 审方规则单条维护与 CSV 批量导入 |
| 预约诊疗 | 号源发布、黑名单管理 |
| 远程会诊 | 专家库维护 |
| 中医药服务 | 适宜技术库维护 |
| 质量安全/传染病目录 | DRG 分组调权、传染病目录报告时限维护 |

### 关键操作

1. **开台流程**：机构管理建机构 → 用户管理逐个建账号（选角色+机构）→
   编码字典核对种子数据 → 各业务目录（互认/审方规则/号源）配置。
2. **建用户**：用户管理 → 填用户名/初始密码/姓名 → 选角色与所属机构 → 创建。
   将初始密码线下告知用户并要求首次登录后修改。
3. **审计追查**：审计日志页按用户名过滤（分页浏览）；每月初用导出接口
   （`GET /api/audit/export`）做归档留存。
4. **互认目录**：共享诊断中心 → 互认目录：新增项目（编码/名称/中心类型/
   互认范围 county 县域｜city 市级）；停用即时生效，开单侧互认将被阻断。

## 第二章 管理层（director）

### 页面清单

| 页面 | 用途 |
|---|---|
| 决策驾驶舱 | 转诊/互认/慢病/基金等核心指标与预警横幅 |
| 绩效考核 | 机构绩效计分排名（转诊结案率/远程诊断量/慢病随访/处方合格率/家医履约） |
| 绩效指标调权 | 五维指标权重与启停调整，实时反映到计分 |
| DRGs 分析 | 出院病例入组、CMI 与组均费用对比 |
| 质量安全 | 不良事件、病历质控、院感上报的督办视角 |
| 医保协同 | 基金监测（县域内/基层支付占比）、**特病申报审核（仅管理层）** |
| 人财物管理 | 公文发文、财务/资产报表视角 |

### 关键操作

1. **月度绩效**：绩效指标调权页确认权重 → 绩效考核页查看排名与明细
   （量类封顶次数与处方合格口径可按考核要求调整参数）。
2. **特病审核**：医保协同页特病申报队列 → 逐条通过/驳回。申报（经办/医师）
   与审核（管理层）职责分离，经办不能自报自批。
3. **驾驶舱预警**：每日查看预警横幅（未处置危急值/慢病超期/医废滞留/缺药），
   点击进入对应页面督办。

## 第三章 医师（doctor）

### 页面清单

患者主索引、患者360视图、就诊记录（经"公卫协同"诊间提醒联动）、双向转诊、
共享诊断中心、危急值操作台、集中审方（开方）、远程会诊、互联网+诊疗、
智慧急救与绿道时间轴、住院管理、慢病管理、家医签约、传染病预警、中医药服务。

### 关键操作

1. **接诊**：患者主索引检索（姓名/证件号/健康卡号）→ 无档则建档（自动生成
   电子健康卡号，同证件号不会重复建档）→ 新建就诊记录 → 患者360视图查看
   全景（就诊/报告/慢病/处方）与诊间公卫提醒。
2. **检查开单与互认**：共享诊断中心 → 选中心类型（影像/心电/检验/病理）开单；
   开单前系统自动互认检查——30 天内同项目已有报告且在互认目录内时提示
   "可互认"，确认后直接引用结果不再重复检查。检验单需推进"采样→转运→核收"。
3. **上级诊断**：共享诊断中心待诊断列表 → 领取（同单只能一人领取）→ 出报告；
   阳性危急结果勾选"危急值"，系统自动通知申请机构。
4. **危急值闭环**：危急值操作台 → 收到通知后**确认接收** → 处置后**反馈处置
   结果**（附说明）。超时未确认会进入催办清单并计入待办。
5. **开处方**：集中审方页开方（可多药品行）。系统规则预审：命中禁忌/相互作用/
   特殊人群等转药师人工审；未命中自动通过。被退回处方按药师意见修改后重开。
6. **双向转诊**：转诊申请（上转/下转，附原因）→ 对方接诊 → 治疗结束结案；
   接诊后可请经办开具医保转诊证明。
7. **慢病管理**：建档（病种/管理机构）→ 随访录入血压/血糖，系统自动分级
   （3 级建议上转）并返回膳食运动指导要点；超期名单每日跟进。
8. **传染病报告**：确诊法定传染病后当日在传染病预警页上报（甲类 2 小时、
   乙丙类 24 小时时限，迟报将进入迟报清单）。

## 第四章 药师（pharmacist）

### 页面清单

集中审方（审核）、中心药房、药事监测、中医药服务（代煎流转）。

### 关键操作

1. **处方审核**：集中审方页"待药师审"队列 → 查看系统预审命中的规则明细 →
   通过或退回（附意见）。每张人工审处方须给出明确结论。
2. **库存调拨**：中心药房页向基层机构调拨药品（库存不足会被拒绝，不产生负库存）。
3. **短缺处置**：药事监测页登记短缺 → 推进"采购中→已送达"；关注采购建议
   与用药监测（重复用药预警）。
4. **代煎流转**：中医药服务页推进代煎订单"配药→煎煮→配送→送达"
   （不煎煮订单自动跳过煎煮环节）。

## 第五章 公卫人员（public_health）

### 页面清单

慢病管理、传染病预警、公卫协同、老年健康、妇幼保健、疫苗接种、家医签约、
远程医学教育、健康宣教（发布）。

### 关键操作

1. **慢病随访**：与医师共用慢病管理页：建档、随访、超期名单清零。
2. **传染病监测**：病例上报；关注多点触发预警（7 天窗口内同病种≥5 例且
   涉及 2 家以上机构升级为高风险）与迟报清单。
3. **公卫事件**：公卫协同页登记事件 → 处置记录 → 结案；维护监测指标。
4. **重点人群**：老年健康（能力评估）、妇幼保健（建册/产检随访）、疫苗接种
   （接种/禁忌登记）按各页面表单录入。
5. **健康宣教**：远程医学教育/健康宣教页起草文章 → 发布后居民端即可浏览。
6. **家医签约**：签约建档 → 履约服务记录（履约量计入机构绩效）。

## 第六章 经办人员（operator）

### 页面清单

患者主索引（建档）、预约诊疗、医保协同、费用结算、住院管理（经办环节）、
智慧急救（调度）、消毒供应、医废追溯、人财物管理、满意度代录（综合管理）、
共享诊断中心（样本物流）。

### 关键操作

1. **建档与预约**：为居民建档（同证件号幂等）→ 预约诊疗页占号（同一号源
   约满即止），就诊到场核销；爽约管理按黑名单规则执行。
2. **医保经办**：结算录入（医保支付+自付=总额校验）；接诊后开具转诊证明；
   特病申报（审核由管理层完成）。
3. **住院与结算**：入院登记/床位安排 → 出院办理 → 费用结算页生成结算单。
4. **急救调度**：智慧急救页建单（选绿道类型：胸痛/卒中/创伤）→ 推进
   "出车→到场→到院→收治"，绿道时间轴逐节点记录（时间须符合先后顺序）。
5. **后勤监管**：消毒供应（批次/申领发放）、医废追溯（收集→交接，超 2 天
   未交接自动预警）。
6. **满意度代录**：电话/现场回访结果在综合管理页代录，统计自动汇总。

## 第七章 居民端（/m）

居民端为手机 H5，无需安装。三个标签页：

| 标签页 | 是否需要核验 | 功能 |
|---|---|---|
| 健康宣教 | 否 | 浏览已发布的健康科普文章（健康常识/慢病防治/妇幼保健/中医养生） |
| 我的档案 | 是 | 查询本人健康档案摘要：慢病管理、就诊记录、检查检验报告 |
| 满意度 | 否 | 对就诊体验提交评分与建议 |

**我的档案使用步骤**：

1. 输入本人**电子健康卡号**（建档时由机构告知，可在就诊时向工作人员索取）
   与**身份证号**双因子核验；
2. 核验通过后查看档案摘要（页面不显示完整证件号等敏感信息）；
3. 核验连续失败会临时锁定约 10 分钟，请确认信息后再试；
4. 请勿在公共设备上留存查询记录，用完关闭页面。

## 附录：常见问题

| 问题 | 处理 |
|---|---|
| 登录提示"账号已锁定" | 连续输错 5 次触发，等 10 分钟或联系管理员核实 |
| 操作提示 403 需要某角色 | 该操作不在本角色职责内（见各章页面清单），需相应角色账号执行 |
| 提示"密码已修改，令牌失效" | 本人（或管理员）改过密码，重新登录即可 |
| 检查开单提示"不可互认" | 项目不在互认目录/已停用/中心类型或互认范围不符，按正常流程重新检查 |
| 危急值不能"处置反馈" | 须先"确认接收"再反馈处置结果（闭环顺序固定） |
| 居民查不到档案 | 核对健康卡号与身份证号是否与建档信息一致；仍失败联系建档机构 |
