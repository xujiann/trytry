# ADR-0020：药品余缺调拨补「调出机构」归属校验

- 状态：**Proposed**（待人工复核 —— CLAUDE.md §8）
- 日期：2026-09-06
- 决策者：待定（需业务侧确认「谁有权把某家机构的药调出去」）
- 相关：**ADR-0019**（同一类缺陷的第一例）、TECH_DEBT **P1-43** 的逐条判定、`app/visibility.py`

## Problem（问题）

`POST /api/pharmacy/transfers`（`app/routers/pharmacy.py:transfer_stock`）
按 body 里的 `from_org_id` 扣减库存，**不校验调用者能不能写这家机构**。
角色守卫是 `require_roles("operator", "pharmacist")`——两个都**不在** `GLOBAL_ROLES` 里。

**已实测复现**：建甲、乙、丙三院与一个挂甲院的 `operator`；乙院备货 200；
甲院 operator 调用调拨接口，`from_org_id=乙院`、`to_org_id=丙院`：

```
① 甲院 operator 调乙院的药给丙院 -> 201 {"org_id":3,"drug_code":"PB01","quantity":40,...}
   库存 org=2 PB01 qty=160      ← 乙院被搬走 40
   库存 org=3 PB01 qty=40       ← 丙院凭空多出 40
```

调用者与这笔调拨的**两端都没有关系**，照样把别人的药搬走了。

比 ADR-0019 那例更重的地方在于：目标池被改挂还能改回来，**药品调拨搬的是实物账**
——批次跟着一起搬（`_fefo_batches` + `_claim_batch`），调出方账上少的那 40 片
在盘点前不会有人发现，而缺药预警看的正是这个汇总。

## Options（可选方案）

- **方案 A：维持现状。**
- **方案 B：只校验调出方**——`assert_org_writable(db, user, body.from_org_id)`。
- **方案 C：调出方与调入方都校验**（与 ADR-0019 同款）。
- **方案 D：不校验，改为记审计 + 事后对账。**

## Advantages（各方案优点）

| 方案 | 优点 |
|---|---|
| A | 零改动 |
| B | 与危害模型完全对齐：**受损的是被搬走药的那一方**；不影响"我把我的药调给别家"这一主用法 |
| C | 最严 |
| D | 不动业务流程 |

## Disadvantages（各方案缺点）

| 方案 | 缺点 |
|---|---|
| A | 任何 operator/pharmacist 可搬任意机构的药，且搬的是实物账 |
| B | 调入方仍可能"被动收货"——但收货不减少任何人的库存，且医共体内上级发货给下级本就是常规 |
| C | **会打断主用法**：余缺调拨绝大多数就是"甲把药调给乙"，调入方本来就不是调用者所在机构；一律要求两端可写等于只有 admin/director 能调拨 |
| D | 事后对账发现不了"谁本来就不该动这批药"，且实物已经搬走 |

## Migration cost（迁移成本）

一行校验 + 回归用例。不动表结构与响应模型；合法路径（从本机构调出）响应字节不变。

## Risk（风险）

- **行为变化**：今天 201 的越权调用变成 403。若线上真有"总院经办代乡镇院发起调拨"的用法，
  会当场报错——这正是需要业务侧裁定的那一点：**代发起是否合法？若合法，应走 director
  还是给经办人显式授权**。
- 与 ADR-0019 的取舍**故意不同**（那例两端都校验，这例只校验调出方），
  理由是两处的"去向"语义不一样：目标池改 `org_id` 是**改归属**，调拨的 `to_org_id` 是**收货**。
  这条差异必须写下来，否则下一个人会以为其中一处漏了。

## Recommendation（建议）

**取方案 B**：校验 `from_org_id`，不校验 `to_org_id`。判据是危害模型——
减少谁的库存就要能写谁，收货方不因收货而受损。

落地清单：
1. `assert_org_writable(db, user, body.from_org_id)`，放在扣减之前。
2. 回归用例：甲院 operator 调乙院的药必须 403 且乙院库存一片不少；
   从本机构调出仍 201；admin/director 跨机构仍 201。
3. 变异验证：拿掉这行守卫，越权用例必须转红、合法用例仍绿。

**需人工复核后再合**（CLAUDE.md §8），并请一并裁定「代发起调拨是否合法」。
