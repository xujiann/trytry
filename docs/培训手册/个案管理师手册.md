# 个案管理师培训手册

**你用的入口**：管理端「全域慢专病」→ **服务团队端·基层执行**（系统按你的账号
自动切到个案管理师视角：在管患者、服务包消耗、待衔接事项）。

## 一、你的核心职责在系统里的对应

| 职责 | 页面/操作 |
|---|---|
| 在管患者全程跟踪 | 工作台「我的患者」+ 患者 360 视图 |
| 风险评估与分层 | 综合风险评估量表（assess_risk_common） |
| 干预计划制订与跟踪 | 干预模板 → 干预记录（planned/doing/done） |
| 复诊安排与提醒 | 复诊计划（超期自动标红） |
| 服务包管理 | 纳管档案上绑定服务包、登记使用量 |
| 跨机构迁出衔接 | 生命周期事件 + 目标机构确认 |

## 二、风险评估的联动（重点）

给患者做综合风险评估后，系统按得分自动分层（低/中/高/极高危），并且：

- **高危及以上**：自动生成复诊计划（14 天内）；
- **配了自动干预模板的病种**：按风险等级自动开出干预计划；
- 没配模板时只建复诊、不静默——"高危了但系统没动静"不允许出现。

评估入口：护理服务页「评估」，或患者 360 视图内发起。

## 三、随访质量：三种状态要分清

| 状态 | 含义 | 计入完成率 |
|---|---|---|
| 已完成 done | 联系上并完成随访 | 分子、分母 |
| 失访 unreachable | 执行了但联系不上（要记录尝试经过） | 只进分母 |
| 逾期 overdue | 到期没人执行 | 只进分母，且进督办清单 |

**失访不要放成逾期**：逾期是"没人管"，失访是"管了没管到"，考核处置完全不同。

## 四、跨机构迁出的正确姿势

患者搬迁/转外地时，在纳管档案上登记**迁出**并填目标机构：

1. 未确认前档案保持在管（患者不能"消失"在两家机构之间）；
2. 目标机构确认后：原档案置"已迁出"、开放任务终止，
   **同时在目标机构自动重建在管档案**（继承风险分级与建档信息，历史任务留在原机构——
   那是原机构的考核留痕）；
3. 患者在目标机构的服务从确认之日重新起算。

## 五、服务包

- 纳管时或纳管后为患者绑定服务包，包内项目有总量与已用量；
- 每次服务后登记使用，工作台上能看到你名下所有包的消耗率；
- 解约走"解绑"，已用量保留可追溯。
