# 村医培训手册（村医赋能端）

**你用的入口**：手机浏览器 / 企业微信打开 `https://<本县域名>/m/doctor`，
用工卫生院发给你的账号登录。绑定二维码由卫生院打印发放（扫码自动带上你的绑定令牌）。

【截图 村医-01：医生移动端登录页】

## 一、每天开工：看"慢专病"页签

登录后点底部 **💗 慢专病**。首屏是你的当日工作台：

- **我的待办**：今天到期的随访、复诊、宣教任务条数；
- **超期任务**：红色数字，先处理这里；
- **待复核转诊**：你发起的上转走到哪一步了；
- **积分余额**：你的服务积分（见第四节）。

【截图 村医-02：慢专病工作台首屏】

## 二、办任务：接收 → 办结

1. 「我的待办」列表里每条任务有两个按钮：**接收**（表示你开始办了）、**办结**；
2. 点办结会弹出"办理结果"输入框，写一句实际做了什么（如"已上门测血压 150/95"）；
3. 要求上传佐证材料的任务（清单里有标注）需先在管理端或让居民在居民端传照片，
   否则办结会被拦下——这是考核留痕要求，不是系统故障。

> 超期未办的任务会自动标红并通知卫生院，**失访不等于超期**：确实联系不上的，
> 让卫生院在随访记录上标"失访"，不要放着等它变超期。

【截图 村医-03：任务办结弹窗】

## 三、转诊：发起上转与承接下转

- **发起上转**：患者血压/血糖控制不住、出现预警症状时，在「转诊办理」里发起，
  写清理由。单子会经服务站→卫生院→县医院逐级审核，你随时能看到走到哪层；
- **承接下转**：县医院把病情稳定的患者转回来时，你的列表里会出现"待承接随访"，
  点**承接随访**即完成闭环——这一步计入你的有效转诊积分。

【截图 村医-04：转诊办理列表】

## 四、积分：怎么挣、怎么花

| 动作 | 积分 |
|---|---|
| 签约纳管一名患者 | 按积分规则入账 |
| 完成一次随访 | 按积分规则入账 |
| 有效上转（患者确实到院就诊） | 按积分规则入账 |
| 承接下转随访 | 按积分规则入账 |

积分在「积分绩效」分段查看，可在卫生院的兑换点兑换物品（凭核销码）。
每类动作有**每日上限**，刷单没有意义。

【截图 村医-05：积分与绩效页】

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 登录提示密码错误 | 找卫生院管理员重置，改密后旧登录全部失效属正常 |
| 待办列表是空的 | 任务要先被指派/认领才进"我的待办"，找团队长确认分工 |
| 办结被拦"要求上传佐证" | 该节点配置了强制留痕，先传照片再办结 |
| 转诊单退回 | 看退回理由，补材料后重新发起，退回不扣分 |
