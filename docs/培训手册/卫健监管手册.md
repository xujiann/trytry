# 卫健监管培训手册（决策监管端）

**你用的入口**：管理端「全域慢专病」→ **卫健管理端·决策监管**，
配合「专病考核与积分」「智能辅助报告端」。需要管理层（director）账号。

【截图 卫健-01：卫健管理端工作台】

## 一、区域运行怎么看

工作台四块：

- **核心指标**：建档、筛查、疑似、目标、在管、随访完成率、转诊闭环率；
- **患者结构**：按病种/风险/机构分布——看的是"管的是不是该管的人"；
- **分级诊疗**：上转/下转量、有效到院率、基层承接率；
- **路径执行**：入径率、按时完成率、暂停中的实例（进入条件未满足的）。

两个口径务必知道：

1. **筛出来 ≠ 管起来**：筛查、目标池、在管是三个数，转化漏斗在报告的
   "筛查转化"段落里；
2. **转诊闭环率分母不含退回与撤回**——退回是"该拦的拦住了"，
   计进分母会逼基层不敢退回。

## 二、考核（专病考核与积分页）

1. **指标库**：每个指标 = 取数口径 + 公式 + 评分规则三段，取数口径是代码里
   唯一实现，各县不可自写 SQL——保证全区数字可对账；
2. **考核方案**：选层级（医院/乡镇/村/团队）、挑指标配权重；
3. **跑分**：选周期（月/季/年）一键计分，结果含分项明细与扣分依据，
   支持逐级下钻到原始业务数据；重跑同周期覆盖旧结果；
4. 村医积分兑换的商品与核销记录也在本页监管。

## 三、订阅报告

在「智能辅助报告端」把自己加为周报/月报订阅人，到点站内消息送达；
报告的指标段落与考核同源，可直接引用到纸质汇报。

## 四、监管红线在系统里的落点

| 监管点 | 系统保证 |
|---|---|
| 数据横向隔离 | 机构只能看/写本机构及下辖数据，越权返回 403 |
| 考核可追溯 | 得分明细带原始取数数字，与业务表随时可核 |
| 佐证真实性 | 任务佐证必须是系统内真实附件，字符串糊弄不过校验 |
| 迁出不甩责 | 跨机构迁出需目标机构确认，确认前原机构继续负责 |
| 失访与逾期分开 | 失访有留痕，不会被算成"没人管" |
