# 全域慢专病全流程管理系统 · 分角色培训手册

一线要的不是"系统有什么功能"，而是"我这个岗位每天进来先点哪里"。
所以手册按**岗位**分册，每册只讲该岗位的日常动线与例外处置，不重复系统全貌
（全貌见 [系统功能清单](../系统功能清单.md)）。

| 分册 | 适用岗位 | 使用载体 |
|---|---|---|
| [村医手册](村医手册.md) | 村卫生室村医 | 医生移动端 H5（`/m/doctor`） |
| [团队成员手册](团队成员手册.md) | 乡镇服务团队医护 | 管理端「服务团队端」+ 医生移动端 |
| [个案管理师手册](个案管理师手册.md) | 专病个案管理师 | 管理端（个案视角工作台） |
| [中心调度手册](中心调度手册.md) | 全程管理中心调度员 | 管理端「全程管理中心端」 |
| [卫健监管手册](卫健监管手册.md) | 卫健局监管人员 | 管理端「卫健管理端」 |

## 演示环境与截图

手册中的【截图】占位指向**演示环境**的对应页面。演示环境的准备：

```bash
cd server
uvicorn app.main:app --port 8000        # 起服务
python scripts/seed_demo.py             # 灌演示数据（含慢专病全链路：
                                        # 20 名在管患者、路径任务、闭环转诊、考核与日报）
```
