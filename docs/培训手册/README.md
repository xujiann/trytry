# 全域慢专病全流程管理系统 · 分角色培训手册

一线要的不是"系统有什么功能"，而是"我这个岗位每天进来先点哪里"。
所以手册按**岗位**分册，每册只讲该岗位的日常动线与例外处置，不重复系统全貌

## 演示环境与截图

手册里的图都是**演示环境实截**（`docs/培训手册/img/`），不是示意图。
界面改了之后重截一遍即可，不必手工点二十次：

```bash
cd server
uvicorn app.main:app --port 8000        # 起服务
python scripts/seed_demo.py             # 灌演示数据（含慢专病全链路：20 名在管患者、
                                        # 村医名下的待办与积分、闭环转诊、考核与日报）
python scripts/capture_manual_shots.py  # 重截全部 19 张图到 docs/培训手册/img/
```

灌完后用下表账号登录截图，各册涉及的页面都已有真实数据：

| 账号 | 密码 | 角色 | 用在哪几册 |
|---|---|---|---|
| `admin` | `admin123` | 平台管理员 | 全部（演示用） |
| `doc_zhen1` | `doctor123` | 卫生院医生 | 团队成员、个案管理师 |
| `doc_village` | `doctor123` | 村医 | 村医手册 |
| `dir_demo` | `doctor123` | 管理层 | 中心调度、卫健监管 |

> 截图统一存放在 `docs/培训手册/img/`，命名 `<分册>-<序号>-<说明>.png`，
> 由 `scripts/capture_manual_shots.py` 生成——**图和界面对不上就重跑一次**。
> 图里全是演示数据（"慢专病演示 00"这类假名字），不含任何真实患者信息；
> 实施期若要用各县自己的环境重截，把脚本的 base_url 换掉即可。
