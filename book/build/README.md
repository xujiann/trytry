# 样书排版构建（book/build）

把 `book/*.md` 书稿按图书正式出版要求排成印刷级 PDF（用于印刷厂制作样书）。

## 用法

```bash
pip install weasyprint markdown pymupdf   # 仅构建期依赖，与 server/ 运行时无关
apt-get install fonts-noto-cjk fonts-noto-cjk-extra   # 思源宋体/黑体（Debian/Ubuntu）
python3 book/build/build_book.py          # 输出 book/紧密型县域医共体信息化建设_样书.pdf
```

同时导出 `book/封面_300dpi.png`（封面位图预览；`--no-cover-png` 可跳过）。
两遍渲染：第一遍统计页数（写入版权页"印张"，并在总页数为奇数时自动补一页
空白，保证双面印刷时封底落在纸张背面），第二遍出成品。

## 版式要点

- **开本** 787mm×1092mm 1/16（成品 185mm×260mm），镜像页边距：订口 23mm、切口 17mm。
- **页面顺序** 封面 → 封二（空白）→ 扉页 → 版权页 → 前言 → 目录 → 五篇十九章 →
  附录 A–F → 后记 → 封三（空白）→ 封底。
- **页码** 前置部分（前言、目录）小写罗马数字居中；正文自第一篇篇章页起排
  阿拉伯页码，位于版口外侧；扉页、版权页、篇章页、空白页不显示页码。
- **书眉** 双码页排书名，单码页排当前章题；章首页不排书眉（页码居中）。
- **分页** 篇章页单页起（右手页，前空自动补白页），章、附录另页起。
- **目录** 由标题扫描自动生成：篇 / 章 / 节（x.y）四级带引导点与页码；
  正文章的三级小节也收录，附录 B/C 的 `###`（表名 / 接口前缀）不收录以免淹没结构。
  PDF 书签（大纲）同步生成，方便屏幕审读。
- **字体** 正文思源宋体 10pt/1.72，标题与强调（`**…**`）思源黑体（中文书惯例：
  黑体表强调，不用斜体），代码 Noto Sans Mono CJK 8pt。全部字体子集内嵌。
- **表格** 三线表（顶底粗线、表头细线），跨页自动重复表头。
- **文字规范化** 构建时自动做两件事：
  1. 段内合行——源文件是硬换行，直接转换会在中文句子中间引入空格；
  2. 直引号成对转全角弯引号（"…"→“…”），行内代码与代码块不动，
     引号不成对的行保持原样并在构建输出中告警。

## 付印前要替换的占位

`build_book.py` 顶部常量集中管理，替换后重新构建即可：

- `PUBLISHER`（现为 `××出版社`）——封面、封底、扉页、版权页四处同步生效；
- 版权页的 CIP 数据、ISBN、版次、定价（由出版社确定后写入模板文字）。

## 给印刷厂的说明

- 本 PDF 为**净尺寸**（185mm×260mm）整合稿：正文无出血元素，可直接数码打样。
- 封面 / 封底为满版色。若印刷厂要求出血与角线，在 `styles.css` 的 `@page`
  中加 `bleed: 3mm; marks: crop;` 后重新构建；正式印刷的封面（含书脊、勒口）
  需在页数与纸张定稿后按书脊厚度另行拼版。
- 总页数已补白为偶数（当前 204 页 = 12.75 印张）。
